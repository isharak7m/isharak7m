### 📌 Featured Projects

#### [JNumj](https://github.com/isharak7m/NumJ) — Numerical Computing Library for the JVM
`Java 21` `Gradle` `JUnit 5` `JMH` `GitHub Actions`
- Zero-dependency library spanning **18 packages**: N-D arrays with stride-based views, 17 dtypes, linear algebra, autodiff, broadcasting, statistics, and I/O
- Type-safe computation engine using sealed interfaces; validated with ~108 JUnit 5 tests and JMH benchmarks
- **Published to Maven Central** as `io.github.isharak7m:jnumj:0.1.0`

#### [Forge](https://github.com/isharak7m/forge) — AI-Powered Fitness Platform
`Java 21` `Spring Boot` `PostgreSQL` `React` `TypeScript` `Docker`
- **6 controllers, 29 REST endpoints** with JWT auth, Flyway migrations, and Swagger/OpenAPI docs
- **4 ML models** built from scratch: linear/polynomial regression, anomaly detection, and trend-based strength modeling
- Strategy-pattern AI tool system with 4 coaching tools and a keyword-based orchestrator
- Full-stack PWA with CI/CD via GitHub Actions to Render + Vercel
